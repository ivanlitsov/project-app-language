# Английский словарь

Учебное приложение на Flutter для изучения лексики. Работает без сервера
и учётной записи; данные сохраняются на устройстве через shared_preferences.

## Возможности

- Бесконечная последовательность по одной карточке: теория и случайные задания.
- Практика: выбор перевода из четырёх вариантов на русский или английский.
- Освоение каждого слова от 0 до 5: правильный ответ +1, ошибка −1, с ограничением по краям.
- В теории кнопки «Знаю» и «Не знаю» открывают следующую карточку без изменения освоения. В практике после сохранения ответа автоматически открывается следующая карточка, результат показывается в уведомлении. Прокрутка не переключает карточки.
- Словарь с поиском и уровнями освоения. В комплекте 48 слов.
- Добавление, изменение и удаление своих слов. Примеры необязательны.
- Настройки направления перевода, показа теории и сброса освоения.
- Светлая, тёмная и системная тема с сохранением выбора.

Свои слова участвуют в общей ленте. Если теория включена, после добавления слова
первой появляется карточка знакомства с ним. Дальше все слова выбираются случайно,
без одинаковых слов в соседних карточках. Освоенные слова тоже продолжают повторяться.
Теория составляет примерно треть ленты; первая карточка при её включении — теория.

После изменения словаря или настроек занятий лента начинается заново. Смена темы сохраняет текущую карточку. Если изменить слово
или перевод, его освоение сбрасывается; изменение примера сохраняет освоение.
Сброс освоения в настройках сохраняет свои слова и настройки.

## Запуск

Нужны Flutter 3.44.4 (Dart 3.12.2) или совместимая более новая версия,
Android SDK и JDK 17 для сборки Android.

```sh
flutter pub get
flutter run
```

Просмотр в браузере: `flutter run -d chrome`.

## Проверка и сборка

```sh
flutter analyze
flutter test
flutter build apk --debug
```

Отладочный APK: `build/app/outputs/flutter-apk/app-debug.apk`.

## Исходники

- `lib/data/initial_words.dart` — начальный набор из 48 слов.
- `lib/models/feed_entry.dart` — случайный выбор карточек и вариантов ответа.
- `lib/models/learning_progress.dart` — освоение слова и настройки, включая тему.
- `lib/models/word.dart` — модель слова.
- `lib/screens/` — лента, словарь, редактор слова и настройки.
- `lib/services/progress_store.dart` — локальное хранение слов, освоения и настроек.
